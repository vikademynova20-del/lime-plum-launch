# Паспорт бота


**Бот-консультант по портфолио**

### Цель и задачи

**Цель:** автоматизировать первые ответы клиентам и подводить их к
заказу услуги.

**Задачи:**

- Отвечать мгновенно и круглосуточно.

- Не терять входящие заявки.

- Освободить время от ответов на однотипные вопросы.

### Целевая аудитория

Потенциальные клиенты, которые хотят узнать о проектах, услугах и
стоимости работы, прежде чем связываться лично.

### Функции для пользователя бота

- **Функция 1** — ответы на вопросы о проектах, услугах и их стоимости.
  **Потребность:** быстро получить информацию без ожидания ответа
  человека.

- **Функция 2** — возможность передать вопрос владельцу.
  **Потребность:** получить помощь, если бот не знает точного ответа.

- **Функция 3** — оформление заявки на услугу. **Потребность:** быстро
  связаться с исполнителем и начать работу.

### Функции для владельца бота

- **Функция 1** — уведомления о новых заявках. **Потребность:** не
  терять потенциальных клиентов.

- **Функция 2** — ответы пользователю через бота. **Потребность:**
  продолжать общение, если требуется личная консультация.

- **Функция 3** — статистика обращений. **Потребность:** понимать, как
  пользователи взаимодействуют с ботом.

### Сценарии использования

**Сценарий 1. Вопрос по портфолио**

Пользователь нажимает /start → Бот его приветствует и предлагает задать
вопрос или выбрать действие → Пользователь задает вопрос → Бот передает
вопрос ИИ → ИИ формулирует ответ → Бот отправляет ответ пользователю.

**Сценарий 2. У бота нет точного ответа**

Пользователь задает вопрос → ИИ не находит точного ответа → Бот
сообщает, что переадресует вопрос человеку → Бот отправляет владельцу
уведомление с вопросом → Владелец отвечает через бота → Бот пересылает
ответ пользователю.

**Сценарий 3. Заявка на услугу**

Пользователь решает заказать услугу → Бот показывает описание услуги и
цену → Пользователь подтверждает заказ → Бот запрашивает контакты,
фиксирует заявку, отправляет ссылку на оплату и уведомляет владельца.

### Инструменты и интеграции

- Telegram Bot API — работа бота в «Телеграме».

- Claude Code — генерация кода.

- Python + aiogram — разработка логики бота.

- DeepSeek — обработка вопросов пользователя.

- База знаний — ответы на основе портфолио.

- Сервер — круглосуточная работа бота после публикации.

### Ограничения и риски

**Ограничения:**

- Работает только с текстом, аудио и изображения пока не распознает.

- Не выдумывает ответы. Если ИИ не уверен — пересылает вопрос владельцу.

- Возможности онлайн-оплаты на данном этапе нет, она появится позже.

**Риски:**

- ИИ может галлюцинировать и давать неточные ответы.

- Токен бота может утечь, если случайно опубликовать его.
