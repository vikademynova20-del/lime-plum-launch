# Victoria's Vibe Launchpad

Создай лендинг-портфолио для начинающего вайб-кодера Виктории. Тёмная сливовая палитра (#15131C), акцент — кислотный лайм (#D4FF5A), шрифты Space Grotesk + Inter. Секции: Hero с сильным заголовком про быстрый запуск лендингов, «Избранные проекты» — 3 карточки кейсов разного цвета, «Что я делаю» — список услуг, «Как я работаю» — пронумерованный процесс из 5 шагов, CTA с кнопками Telegram и Email.
